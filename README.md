# Rthoptera Desk

Desktop app for insect bioacoustics analysis, based on the Rthoptera package.

## Download

Go to the [Releases](https://github.com/panchorivasf/Rthoptera-Desk/releases) page and download the installer for your operating system:

| OS | File to download |
|---|---|
| Windows | `.msi` or `.exe` (NSIS installer) |
| macOS (Apple Silicon) | `.dmg` labeled `aarch64` |
| macOS (Intel) | `.dmg` labeled `x86_64` |
| Linux | `.deb` (Debian/Ubuntu) or `.AppImage` (universal) |

### Which macOS file do I need?
- **Apple Silicon** (M1, M2, M3, M4): download the `aarch64` `.dmg`
- **Intel Mac**: download the `x86_64` `.dmg`

If you're unsure, click the Apple menu → **About This Mac**. If it says "Apple M..." you have Apple Silicon; if it lists an Intel processor, download the `x86_64` version.

## About

Rthoptera Desk is a cross-platform desktop application for analyzing insect sounds. It is built with [Tauri](https://tauri.app).
